ПРОВЕРКА НОУТБУКА С ФЛЕШКИ
==========================

Короткая инструкция по запуску и файлам: START-HERE.txt

Что запускать
  RUN.cmd        полная проверка, ~35 мин
  RUN-QUICK.cmd  быстрая, ~6 мин (проверить, что всё работает)
  CLEANUP.cmd    доубрать за тестом, если окно закрыли посередине

Запускать двойным щелчком — «от имени администратора» выбирать не нужно: скрипт сам
попросит права (нужны для SMART диска, Secure Boot, TPM). Если отказать — предложит
продолжить без них, все тесты нагрузки пройдут.

Перед запуском
  1. Подключить зарядку.
  2. Закрыть программы.
  3. MSI: в MSI Center выбрать Extreme Performance и нужный режим видеокарты.
     GIGABYTE A16: в GiMATE выбрать «Игры» / Performance; использовать штатную зарядку 150 Вт.
     Для сравнения «до/после» режимы в обоих замерах должны совпадать.

Что делает (по порядку)
  - сведения: модель, серийный номер, BIOS, процессор, планки памяти по слотам,
    видеокарта и её лимит мощности, экран, сеть, проблемные устройства, виртуализация;
  - батарея: заводская и текущая ёмкость, циклы (powercfg /batteryreport);
  - накопители: SMART (Windows + CrystalDiskInfo), скорость (DiskSpd, файл 1 ГБ во временной
    папке, удаляется сразу);
  - 2 мин простоя — фон;
  - процессор: Cinebench R23 Multi 10 мин;
  - видеокарта: FurMark 10 мин;
  - процессор + видеокарта вместе 10 мин (проверка охлаждения и блока питания);
  - уборка и отчёт.

Результат
  reports\<дата>_<модель>_<серийник>[_метка]\
    report.html   отчёт с вердиктами
    summary.txt   короткая сводка — удобно отправить в чат
    hardware-inventory.json  сверка ожидаемых и обнаруженных комплектующих
    sensors.csv   датчики процессора/ACPI/батареи раз в 2 с
    gpu.csv       датчики видеокарты (nvidia-smi) раз в 1 с
    остальное     сырые выводы программ, battery.html, run.log, state.json (что убрано)

Что НЕ меняется
  Ничего не устанавливается, драйверы не ставятся, настройки не трогаются.
  Сон/отключение экрана блокируются только на время работы окна (SetThreadExecutionState).
  Временное удаляется: тестовый файл DiskSpd, настройки Cinebench в %APPDATA%\Maxon.
  Windows сама отмечает факт запуска программ в своих журналах (Prefetch и т. п.) — это не трогаем.

Ориентиры из обзоров и спецификаций
  Для MSI Katana 17 B13V, MSI Vector GP76 12UG* и GIGABYTE Gaming A16 GA63H / 3TH
  (Ryzen 7 260 + RTX 5050) отчёт показывает ориентиры со ссылками и сравнивает с ними
  первый проход Cinebench R23.
  Для GIGABYTE CPU-ориентир — 16 068 баллов из обзора 3DNews на A16 3VH с тем же
  Ryzen 7 260, но RTX 5060: это приближённое сравнение без вердикта «норма/плохо».
  Лимит мощности CPU проверяемого экземпляра наш набор не измеряет.
  GPU — RTX 5050 8 ГБ. В обзоре A16 3TH (Ultra-tech, iXBT Live) лимиты по режимам:
  Performance — до 85 Вт, Balance — до 70 Вт, Silent — до 50 Вт. GIGABYTE Japan указывает
  75 Вт: причина расхождения не установлена. Отчёт показывает потребление и фактический
  лимит драйвера, но одни ватты не определяют исправность GPU. Экран — 16 дюймов, 1920x1200,
  165 Гц; батарея — 76 Вт·ч. Объёмы RAM и SSD считываются с проверяемого ноутбука.
  Профиль GIGABYTE выбирается по модели/плате/SKU и только при Ryzen 7 260 + RTX 5050.
  Отчёт можно пересобрать без повторного теста:
    powershell -ExecutionPolicy Bypass -File checkup.ps1 -ReportFrom reports\<папка>

Ограничения
  В «Итоге» указаны измерения, референс и основание каждой оценки. Пороги температуры
  GPU (84/88 °C) и доли теплового троттлинга (2/15%) — диагностические правила набора,
  а не официальные пределы производителя. Данные обзоров подписаны с условиями нагрузки.
  ACPI-температура приводится справочно, без оценки как по датчику CPU Package.
  Таблица «Сверка комплектующих» показывает CPU, GPU/VRAM, RAM по слотам (марка, артикул,
  серийный номер, ёмкость, паспортная и рабочая скорость), накопители, экран и батарею.
  Для A16 проверяются заявленные Ryzen 7 260 и RTX 5050 8 ГБ. DDR5-5600 — возможность
  платформы: более медленная память помечается для проверки, без утверждения о замене.
  Без полного SKU/исходной ведомости RAM и SSD заводскую комплектацию подтвердить нельзя.
  Номинальный объём RAM/SSD из объявления пока неизвестен; в таблице это явно отмечено.
  Официальный лимит CPU A16 3TH не найден. AMD указывает для самого Ryzen 7 260 TDP
  45 Вт и cTDP 35–54 Вт; это не измерение мощности конкретного ноутбука под нагрузкой.
  Температура процессора — по ACPI-зоне прошивки (без драйвера точнее не получить).
  Обычно близка к температуре процессора; для сравнения «до/после» на одном ноутбуке подходит.
  Мощность процессора без драйвера Windows не отдаёт.
