ПРОВЕРКА BIOS И ОСМОТР GIGABYTE GAMING A16 GA63H

КАК ПРОВЕРИТЬ ПАРОЛЬ BIOS

1. Перезагрузи ноутбук и сразу несколько раз нажимай F2.
2. В BIOS найди раздел Security. Проверь статусы:
   - Administrator Password / Supervisor Password;
   - User Password;
   - HDD / SSD Password, если такой пункт есть.
   Нормально: Not Set / Not Installed / Clear. Названия зависят от версии BIOS.
3. Если стоит Set / Installed или появляется запрос пароля — продавец должен
   снять пароль при тебе. После этого перезагрузи ноутбук и самостоятельно
   повторно зайди в BIOS.
4. Сам по себе вход в BIOS не гарантирует отсутствия пароля: возможен режим
   только для просмотра. Проверь именно статусы паролей и доступ к настройкам.
5. Если ничего не менял, выйди через Exit Without Saving / Discard Changes.

ВИРТУАЛИЗАЦИЯ

Ryzen 7 260 поддерживает AMD-V. Настройка в BIOS обычно называется SVM / SVM Mode.
Точный путь меню для установленной версии BIOS не подтверждён.
Виртуализация нужна для WSL2, Docker и виртуальных машин.

В Windows: Ctrl+Shift+Esc -> Производительность -> ЦП -> «Виртуализация».
Желательно увидеть «Включено».

Если выключено — это само по себе не неисправность. Попроси продавца включить
SVM, сохранить настройку и проверить статус в Windows после перезагрузки.
Если пункт BIOS скрыт, а Windows показывает «Включено», искать его необязательно.

Не сбрасывай BIOS и не очищай TPM при осмотре: это не проверка отсутствия пароля
и может вызвать запрос ключа восстановления BitLocker. Secure Boot и TPM сами
по себе пароль BIOS не означают.

ЧТО ЕЩЁ ПРОВЕРИТЬ

- Зарядка: штатный адаптер 150 Вт, целый провод, разъём без пропадания питания.
- Комплектация: Ryzen 7 260, RTX 5050 8 ГБ, объёмы RAM и SSD — сверить
  с объявлением и таблицей «Сверка комплектующих» в отчёте.
- Экран: 1920x1200, 165 Гц. Открой однотонные белый, чёрный, красный, зелёный
  и синий экраны; проверь битые пиксели, пятна, полосы и подсветку.
- Корпус: петли, трещины возле креплений, винты, следы жидкости.
  Тачпад и днище не должны выпирать.
- Работа: клавиатура, тачпад, USB, HDMI, Wi-Fi, звук, микрофон и камера.
- Нагрузка: запусти RUN.cmd с флешки при подключённой зарядке и режиме
  «Игры» / Performance в GiMATE. Проверь отсутствие зависаний, перезагрузок
  и артефактов изображения. Порядок запуска — в START-HERE.txt.
- Доступ: ноутбук должен передаваться без паролей продавца и корпоративных
  ограничений. Проверь «Параметры -> Учётные записи -> Доступ к работе или учёбе»;
  отсутствие подключений в этом разделе не гарантирует отсутствия всех привязок.
