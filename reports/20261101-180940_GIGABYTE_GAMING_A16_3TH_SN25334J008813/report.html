Примечания к восстановленному отчёту

Отчёт восстановлен 01.11.2026 из сохранённых данных, без повторного запуска нагрузок.

Причина сбоя: PowerShell 5.1 прочитал массив disk.json как один вложенный массив. SSD и USB-флешка объединились в один объект; форматирование массива как числа вызвало System.Object[] -> System.Double. Обработка исправлена, флешка исключена из сведений о внутреннем SSD.

CPU: основной Cinebench остановлен скриптом через ~20 минут по тайм-ауту. Финальной строки CB нет. В журнале сохранилось 10 завершённых проходов: среднее 16447.563, первый 16614.288, последний 16572.314 балла. Это частичный результат. Почему процесс не завершился вовремя, по журналу установить нельзя. Совместный тест завершился с итогом CB 9152.38.

SSD: данные Windows и CrystalDiskInfo расходятся. Windows: износ 0%, наработка не получена. В smart-crystaldiskinfo.txt: здоровье 98%, процент использования 2%, наработка 292 ч, записано 4784 GB, прочитано 3059 GB, 32623 включения, 15944 небезопасных отключения. Критическое предупреждение, ошибки целостности данных и записи журнала ошибок — 0. Счётчики включений/небезопасных отключений необычно велики относительно наработки; причина не установлена, по ним одним неисправность не подтверждается. Серийный номер из CrystalDiskInfo: 511250515100010150; Windows сообщает другой идентификатор. Строка «износ 0%» ниже относится только к Windows API, для оценки износа учитывайте исходный SMART.

Экран: сохранённый снимок сообщает текущий режим 1920x1200 @ 165 Гц, но поле максимальной частоты EDID содержит 60 Гц. Без исходного EDID проверить корректность считывания нельзя; это расхождение данных, не доказательство неисправности экрана.

Основная нагрузка GPU: максимум 72 °C, тепловые флаги не отмечены в 597 загруженных отсчётах. Питание от сети было во всех 1324 отсчётах датчиков, остаток батареи не уменьшился. Датчик ACPI достигал 93.9 °C; это не измерение CPU Package. RAM: один модуль 16 ГБ DDR5-5600. Батарея: 97.5% заводской ёмкости, 11 циклов.
